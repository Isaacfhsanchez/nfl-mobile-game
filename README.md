# Pocket NFL Rush

A lightweight football game prototype built for mobile browsers.

## Play it locally

1. Open a terminal in this project folder.
2. Start a local web server:

```bash
python3 -m http.server 8000
```

3. Open `http://localhost:8000` in your browser.

## Controls

- Run: pick a ground play to gain yardage.
- Pass: try a deep or short completion.
- Defend: stop the CPU offense when they have the ball.
- New Game: resets the match.

## Features

- Mobile-first UI
- Touch-friendly controls
- Scoreboard and game clock
- Drive simulation with first downs and touchdowns
- CPU opponent logic

## Goal

Score more points than the CPU before the clock reaches zero.
